# 🖼️ 第八篇 · 图资（参考图资产）生产指导

> **图资是生成链的唯二输入之一（参考图 × 提示词模板），也是当前质量天花板的决定因素。**
> av_offset 实验已证伪「后处理修质量」（17.D §13.3）——**图资就是最前沿的质量杠杆。**

## 第 28 章 图资的技术规格（硬要求）

### 28.1 生成链对图的真实处理方式（实勘脚本）

```python
# scripts/batch_ref2va_nf4.py 实勘结论——零预处理直传
ref_image = Image.open(img_path).convert("RGB")          # 仅转 RGB，无 resize/crop
references=[{"type": "image", "image": ref_image}]       # 原图直接进 API
HEIGHT, WIDTH = 480, 832                                 # 输出固定 832×480 横版
```

**推论（最重要的一条）**：构图适配完全由远端 API 二次裁切决定，本地不可控。
当前 person_a 为 1280×1158 近方形 → 裁成 832×480 横版时**上下被砍 62%**，
人脸占比与位置全凭 API 算法——这正是 SyncNet conf 偏低（1.6 vs 官方 demo≈10）
的构图性因素之一。

### 28.2 硬规格清单（提交前逐项核对）

| # | 项目 | 要求 | 原因 |
|---|------|------|------|
| 1 | **画幅比例** | **832:480（26:15，≈1.73:1）横版**，最低 16:9 | 与输出画幅一致，杜绝 API 二次裁切毁构图 |
| 2 | **分辨率** | ≥ 832×480，推荐 1664×960（2 倍冗余） | 低于输出分辨率会放大糊化 |
| 3 | **人脸位置** | 面部居中偏上，头顶留白 5~10%，下巴线在画面下 1/3 | 832×480 特写构图标准 |
| 4 | **人脸占比** | 肩上特写（head-and-shoulders），面部高 ≥ 画面高 40% | SyncNet 口型检测需足够像素；占比过小 = conf 天花板直接压低 |
| 5 | **朝向** | 正脸或偏转 ≤ 15°；双眼可见 | 侧脸/仰俯使口型轨检测失败率骤增 |
| 6 | **嘴部状态** | 自然闭合或微露齿，勿大笑/张口 | 生成起始帧口型决定全片口型基线 |
| 7 | **遮挡** | 无口罩/墨镜/刘海遮唇/手托腮 | 口型区被遮 = 同第 4 条后果 |
| 8 | **光照** | 均匀正面光，脸部无硬阴影、无过曝 | 阴影会被模型理解为立体结构并放大 |
| 9 | **背景** | 纯色/简洁虚化，与发色/肤色有对比 | 复杂背景诱发边缘伪影 |
| 10 | **格式** | PNG 或 JPG，RGB 三通道，单图 1~5MB | 脚本强制 convert("RGB")，CMYK/RGBA 会被转换但可能偏色 |

### 28.3 一票否决项

以下任一命中直接退回，不进筛选夜：侧脸 >30° / 嘴部被遮挡 / 分辨率 <832×480 /
竖版人像（9:16 类，横裁后人脸必残）/ 多人同框 / 明显美颜磨皮痕迹（口型细节被抹平）。

## 第 29 章 图资入库 SOP（五步）

```bash
# Step 1 放置（命名规范：person_{编号}.png，编号递增，禁中文/空格）
cp ~/Downloads/新形象.png ref_images/person_b.png

# Step 2 确认 GPU 空闲 + 接电（守卫铁律：生成进程存在则批次拒绝）
pgrep -fl batch_ref2va || echo "GPU 空闲 ✓"; pmset -g batt | head -1

# Step 3 筛选夜点火（新图初始化双 seed 筛选——batch1004 验证过的模式）
#   方式A（推荐，不污染演进状态）：CLI 直传 seeds
nohup caffeinate -is bash -c '
/opt/miniconda3/envs/h3-m4/bin/python scripts/batch_ref2va_nf4.py --batch <下一批次号> --seeds 42,10
echo "[watcher] 生成退出，接五段闭环"
/opt/miniconda3/envs/h3-m4/bin/python scripts/pipeline-tools/pipeline_auto.py --batch <下一批次号> --auto
' >> logs/batch_manual_$(date +%Y%m%d).log 2>&1 & disown

# Step 4 次日晨检（手册 17.C 第 12 章五查判定表）

# Step 5 精评写回：人工看片打分 → set_human → analyze → update_seed_list（17.D 第 15 章）
#   新图图源独立收敛：person_a=[42] 的演进结果不干扰 person_b
```

> **注意**：批次号全局递增（dashboard 以 batch 为唯一聚合键）；一张新图一个筛选夜，
> 禁止多张新图混入同批（会互相污染 seed 演进的归因）。

## 第 30 章 图资质量与 conf 的关系标尺

| 构图情形 | 预期 conf 带间 | 依据 |
|---|---|---|
| 本项目现状（方形图二次裁切 + 5.2s 数字人） | 1.5~1.9 | person_a 实测 1.61~1.85（含平移实验上界） |
| 28.2 全项达标的横版原生图 | 预期 ≥ 2.5 | 正脸占比↑ 直接提升口型轨质量 |
| 官方 demo 域（正脸特写 25fps 标准裁剪） | ≈10 | 跨域对照，勿当本项目基线 |

**判读规约**：conf 只做同图跨 seed/跨批相对比较；换图后**旧标尺作废**，以新图
首筛选夜的 conf 重建基线（17.D §13.2 相对标尺原则）。
