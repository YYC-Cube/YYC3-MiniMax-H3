> **方法**：两卷全目录 `du`/`ls` 实测 + 逐 README 精读；可用项已按「对应端」拷贝入库（见 §一末列）。

## 一、`/Volumes/Models/MiniMax-数据集`（MiniMax 官方六件，397M）

| 数据集 | 体量 | 协议 | 内容 | **对应端用途（YYC³ 映射）** | 汲取动作 |
| --- | --- | --- | --- | --- | --- |
| **TTS-Multilingual-Test-Set** | 3.5M | CC-BY-SA-4.0 | 24 语种 × 100 测试句 + MCV 双说话人（男/女）克隆参考音频；`speaker/`+`text/` 结构化落盘 | **数字人语音质检基准**——音色克隆零样本评测，对齐 piper-voices 工具链与五步闭环的语音侧验收；未来 TTS 替换/升级时的回归锚 | ✅ README 入库 |
| **role-play-bench** | 247M | Apache-2.0 | 中英双语角色扮演评测（`seeds_zh` 等 config，1K–10K 样本） | **AI Family 八 Agent 角色一致性回归评测**——ReAct-C 九步链的角色不漂移验收，可直接做人工精评之外的客观第四层 | ✅ README 入库 |
| **VIBE** | 280K | MIT | Web/全栈开发 agent 评测（agent-as-a-verifier） | **Family-Coder 评测补充**（与 `tools/` 本地 14B 模型对应） | ✅ README/README_CN 入库 |
| **OctoCodingBench** | 1.1M | MIT | 代码 agent 基准（en） | **Family-Coder 评测**第二锚 | ✅ README/README_CN 入库 |
| **MR-NIAH** | 76M | MIT | 多轮大海捞针（长上下文跨轮检索，lifelong companion 场景） | **Agent 长对话记忆评测**——漫剧六阶段跨场一致性 / agent 网关会话保持的验收参考 | ✅ README 入库 |
| **SynLogic** | 69M | MIT | 中英逻辑推理（easy 等档位） | **推理训练/评测语料**——对接 DGX-Spark 训练知识集的消费矩阵 | ✅ README 入库 |

**汲取落点**：`docs/YYC3-MiniMax-H3-数据集参考/<数据集名>/README*.md`（原版拷贝，未改动）。数据本体留在卷上（397M 不入库），消费时按卷路径直读。

**优先级建议**：①TTS 测试集（直接补五步闭环的语音验收空白，P1）②role-play-bench（AI Family 客观评测，P1）③其余按 DGX 训练排期消费。

## 二、`/Volumes/Models/YYC3-音视开源项目`（工具链归档镜像，33.6G）

| 目录 | 体量 | 身份实测 | 与生产体系关系 |
| --- | --- | --- | --- |
| ComfyUI | 31G | 上游完整克隆 | ≈ 内盘 `YYC-Cube/tools/ComfyUI`（主副本）；卷份为归档 |
| kohya_ss | 2.3G | 训练 GUI | ≈ `tools/kohya_ss`；DGX LoRA 训练（docs/10 P5）候选项 |
| **MiniMax-H3** | 255M | **官方 GitHub 仓完整克隆（含 assets）** | `skills/h3-prompt-writing/references/ref-en.txt` 与我方 `prompts/official` **md5 同源**（实测一致）；assets 样例视频可用于质量对照 |
| DiffSynth-Studio | 21M | 推理引擎上游 | ≈ 本仓 `vendor/` submodule |
| syncnet | 138M | 权重+源码 | 权重与本仓 `models/syncnet` md5 一致（2026-10-22 已在内盘去重）；卷份归档 |
| piper-voices | 60M | TTS 音色 | ≈ `tools/piper-voices`；配 §一 TTS 测试集可做音色质检闭环 |
| **dgxspark_comfyui_minimax_h3** | 688K | **docs/12 深析的社区部署包原件** | README/BENCHMARK.zh-CN.md 已拷入库；GB10 Week-1 性能锚点部署脚本（`install_wizard.py`）在此卷 |

**定性**：卷1 是**冷备份/分享盘**（对应端=归档层），不建议当生产读取路径；冗余清理**不动卷**（备份主权），仅记录 md5 一致性事实。卷根另一份 268G 母版与 68G NF4 备份见 `/Volumes/Models/MiniMax--MiniMax-H3/README.md` 与 `MiniMax-H3-NF4/YYC3-ASSET-LABEL.md`。
