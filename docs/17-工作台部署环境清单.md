# 工作台部署环境清单（apps/console 单端口）

> 配套：`apps/console/.env.example`（占位模板）；真值一律存放 `.secrets/`（600 权限，gitignore 隔离）。

## 一、部署形态速览

| 形态 | 命令 | 依赖 env |
| ---- | ---- | -------- |
| dev（本机联调） | `pnpm --filter console dev`（Vite 3030 代理 /api → 3031） | 无（回环放行） |

### 2.3 令牌鉴权（推荐配置；未配置仅回环放行）

| 变量 | 覆盖端点 | 校验方式 |
| ---- | ---- | ---- |
| `TASKS_CLAIM_TOKEN` | `/api/tasks/**` | `X-Claim-Token` 常量时间比较 |
| `PIPELINE_TOKEN` | `/api/pipeline`、`/api/score` | `Authorization: Bearer` |
| `H3_SESSION_KEY` | `/api/session`（私网外签发） | `X-Session-Key` 预共享密钥 |

**会话令牌机制**：SPA 启动先取 `/api/session`（私网/回环或 H3_SESSION_KEY 放行）→ 获得 HMAC-SHA256 签名 12h 令牌 → 内存持有附加到后续请求。**URL 传密钥永禁**（P1-S3 铁律延续）。

**鉴权矩阵（2026-10-05 实测）**：远程无令牌 401（fail-closed）✓ · 有效会话令牌放行 ✓ · 伪造/过期令牌拒收 ✓ · 回环直连（dev）✓ · 令牌配置后 loopback 不再豁免 ✓
